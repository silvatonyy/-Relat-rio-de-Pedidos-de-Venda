# -Relatorio-de-Pedidos-de-Venda
Desenvolva  um relatório que ajude o time de vendas a monitorar os pedidos emitidos em um determinado período. O relatório deve exibir o número do pedido, a data de criação e o código do cliente, com base na tabela VBAK.

**Objetivo do Projeto**

*Criar uma interface com intervalo de datas
*Consultar a tabela VBAK
*Listar os pedidos encontrados com suas datas e clientes
